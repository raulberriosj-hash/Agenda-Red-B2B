# Logos

Marca Inelcom en SVG, tal como sale de los archivos de origen (no redibujar ni recolorear).

- `inelcom-logo-horizontal.svg`: logotipo horizontal, wordmark INELCOM en tinta `#1d1d1b` con el isotipo y el descriptor en cyan `#00bdd4`. Para fondos claros (`background-primary`, `background-secondary`). Margen de respeto mínimo: `space-4` alrededor.
- `inelcom-isotipo-fondo-oscuro.svg`: isotipo cyan sobre su propio fondo `#1c1c1c` (el rectángulo viene dentro del SVG). Para avatares, favicons, splash y superficies oscuras.

El cyan de los logos (`#00bdd4`) difiere levemente de `corporate-500` (`#00bfd6`); en los logos manda el archivo, en la UI el token.
